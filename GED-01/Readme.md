# 🕹️ Nombre del Juego
**Bloquecidio Matematico**

---

## 🎯 Descripción
**¿De qué trata?**  
Es un juego educativo y de obstaculos donde el jugador debera llegar al bloque de pregunta para resolver un pequeño ejercicio matematico para asi aumentar sus conocimientos

**¿Cuál es el objetivo del jugador?**  
El objetivo es lograr aumentar el conocimiento basico del area de matematicas 

**¿Cuál es la mecánica principal?**  
El jugador selecciona esquiva, salta y se mueve para evitar los obstaculos donde al final del mapa podra responder un ejercicio matematico mediante 4 opciones, si responde bien ganara puntos y si responde mal los perdera

---

## 🧩 Género
**Estrategia / Educacional**
