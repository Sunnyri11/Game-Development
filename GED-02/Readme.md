# 🕹️ Nombre del Juego
**Reci-Trail**

---

## 🎯 Descripción
**¿De qué trata?**  
Es un juego de limpieza donde se debera limpiar la carretera poniendo la basura en su respectivo lugar

**¿Cuál es el objetivo del jugador?**  
Conducir por cuestas muy empinadas recogiendo la basura de las calles y depositándola en el contenedor correcto (plástico, papel y vidrio) antes de llegar a la cima. 

**¿Cuál es la mecánica principal?**  
El jugador acelera una motocicleta Trail para subir la colina. Al pasar sobre un residuo, se detiene brevemente y debe presionar el botón del color correcto (Amarillo para plástico, Azul para papel, Verde para vidrio) para clasificarlo.
