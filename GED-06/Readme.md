# 🕹️ Nombre del Juego
**Cookie Diner**

---

## 🎯 Descripción
**¿De qué trata?**  
Es un juego educativo y de simulación donde el jugador administra una pequeña cocina y debe atender clientes, elegir ingredientes y tomar decisiones estratégicas para mantener la rentabilidad del negocio.

**¿Cuál es el objetivo del jugador?**  
El objetivo es lograr el equilibrio entre calidad, rapidez y economía para maximizar las ganancias sin perder la satisfacción del cliente.

**¿Cuál es la mecánica principal?**  
El jugador selecciona ingredientes, cocina los pedidos y gestiona los recursos mientras evita que los clientes se enfaden. Cada decisión afecta el resultado final y la puntuación.
